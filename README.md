1. Header
<br>
Header는 h1으로 작성된 로고와 nav를 통해 작성된 메인 메뉴로 구성되어 있습니다
<br>
<img width="109" height="58" alt="로고" src="https://github.com/user-attachments/assets/d7771321-a1f5-437e-bb17-390267a68af8" />
<br>
- 로고
<br>
로고에 마우스를 hover 시 mouse pointer가 손가락 모양으로 변합니다
<br>
<img width="489" height="51" alt="메인메뉴" src="https://github.com/user-attachments/assets/5a72bc18-3455-47ae-b918-b441a55e87b6" />
<br>
- 메인 메뉴
<br>
각 카테고리에 마우스를 hover 시 mouse pointe가 손가락 모양으로 변합니다
<br>
각 카테고리를 click 시 해당 카테고리에 밑줄 효과와 함께, 글자 색상이 회색으로 변합니다
<br>
<br>

2. Main
<br>
Main은 figure를 통해 작성된 비디오, h2를 통해 작성된 슬로건, ul을 통해 작성된 상품으로 구성되어 있습니다
<img width="1883" height="947" alt="메인화면" src="https://github.com/user-attachments/assets/d672384c-9e41-429e-9677-6f6a1ac3ff8d" />
<br>
- 비디오와 슬로건
비디오는 홈페이지 접속 시 자동으로 재생되며, 상태는 루프와 음소거입니다
<br>
<img width="993" height="748" alt="상품" src="https://github.com/user-attachments/assets/d51e8ff3-48bc-4850-95f7-373329173ebe" />
- 상품
상품은 4열 2행으로 구성되어 있으며, 각각의 상품에 마우스를 hover 시 scale이 1.05배 부드럽게 확대됩니다
<br>
span과 s 코드를 이용해 할인율 및 정가를 표시할 수 있습니다
<br>
<img width="884" height="34" alt="바닥글" src="https://github.com/user-attachments/assets/7e195ac3-323e-4142-8f2c-227bcb111a97" />
3. Footer
Footer는 화면 너비인 1920px을 채우고 있으며, position을 fixed로 하여 스크롤에 구애받지 않고 밑바닥에 존재합니다
<br>
Footer의 색상은 반투명하여, 스크롤 시 상품을 가리지 않아 사용자의 흐름을 방해하지 않습니다.
